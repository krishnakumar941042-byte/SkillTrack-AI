
# SkillTrack AI — Smart Learning Dashboard

## 1. Project Purpose
A functional learning dashboard built with Python and Django.

## 2. Core Features
- Learning overview and progress tracking
- Courses and lessons
- Python practice lab
- Study planner and daily goals
- XP, missions and achievements
- Analytics and reports
- AI learning assistant
- Theme and learning preferences

## 3. Technology Stack
- Python
- Django
- HTML, CSS and JavaScript
- SQLite
- Chart.js
- Git and GitHub

## 4. Important Requirements
- Buttons and forms must perform real actions.
- Learning data must be saved in the database.
- Charts must use real saved data.
- Validate user inputs.
- Do not execute untrusted Python code directly on the server.
- The core dashboard must work without an AI API.
- Login is not required in the initial version.

## 5. Development Phases
1. Project Foundation
2. Premium UI Design
3. Backend and Database
4. Learning Management
5. Python Practice Lab
6. Study Planner
7. Gamification
8. Analytics and Reports
9. AI Learning Assistant
10. Profile and Settings
11. Testing and Bug Fixing
